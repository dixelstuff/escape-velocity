# Contact adjustment data

`contact-data.mjs` is a generated, frozen local lookup, built by `scripts/build-contact-data.mjs`. It contains vocabulary words, English frequency values and unordered exact two-word phrase-pair IDs. It contains no dictionary definitions or corpus text. Phrase presence is attestation, not a guarantee of intended sense or coverage of all phrases.

The policy is `frequency-phrases-v1`. Its settings and migration boundary are saved in each game as `contact_adjustment: {version, after}`. The data for this version must remain frozen so saved histories replay identically. A future data revision needs a separately preserved rule/data version; do not overwrite this table in place with a new dictionary dump.

## Sources and modifications

- **Princeton WordNet 3.0**, Copyright 2006 Princeton University. The original license is included in `WORDNET-LICENSE.txt`. Source: <https://wordnet.princeton.edu/>. Modification: retain exact two-component underscore/hyphen headwords whose components are in the game vocabulary, normalise existing curated UK/US spellings, and encode unordered pair IDs. Synonyms, gloss co-occurrence, longer expressions and inferred morphology are excluded.
- **Open English Wordnet Community, Open English Wordnet 2025**, derived from Princeton WordNet, under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Source and contributors: <https://en-word.net/downloads> and <https://github.com/globalwordnet/english-wordnet>. Frozen input: <https://en-word.net/static/english-wordnet-2025.zip>. Apply the same exact two-component extraction and spelling normalisation, then union with the Princeton pairs. This is the standard lexical edition, without the separate proper-name expansion.
- **English Wiktionary contributors**, extracted by **Kaikki/Wiktextract**, under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Source: <https://kaikki.org/dictionary/English/pos-phrase/index.html>; downloadable snapshot: <https://kaikki.org/dictionary/English/pos-phrase/kaikki.org-dictionary-English-by-pos-phrase.jsonl>. The source page identifies the Wiktionary dump as 2026-10-01 and extraction as 2026-10-30. This is the complete *phrase part-of-speech subset*, not all Wiktionary noun/verb compounds. Modification: retain exact lowercase two-word/hyphenated headwords in the game vocabulary with at least one sense not tagged slang, archaic, obsolete, pronunciation-spelling, abbreviation or form-of; normalise spelling and encode unordered pairs. No glosses, example sentences or the old targeted validation-route snapshot are used. Original entries and contributor histories are available through <https://en.wiktionary.org/>. The modified Wiktionary-derived pair data and the combined generated data table are provided under CC BY-SA 4.0, subject also to the original Princeton attribution/license.
- **wordfreq 3.1.1**, English Zipf frequency data. Project: <https://github.com/rspeer/wordfreq>; data license CC BY-SA 4.0 (see upstream attribution and notices). The existing complete game-vocabulary frequency snapshot is frozen in `reports/rare-word-contact/frequency.json`. Modification: represent frequencies as exact hundredths and use the maximum frequency among curated UK/US equivalents. There is no new stemming or word-family equivalence.

`reports/contact-live/lexicon-sources.json` preserves the extracted source headwords and archive hashes; `data-manifest.json` preserves build statistics and hashes. These extracts were made uniformly across the existing game vocabulary, without selecting phrases from player routes or desired test outcomes. The historical played-shot comparison finds no additional outcome changes from the two supplementary phrase sources in the available sample. They add coverage for future words, not a claimed measured improvement in player enjoyment.

The runtime does not consult these websites. Lookup data is local and loaded with the engine; indexed binary search and word maps provide synchronous per-shot access. Source attribution here applies to the data; gameplay/scoring code is separate.
